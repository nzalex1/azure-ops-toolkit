# Azure Ops Toolkit

A collection of reusable scripts, commands, snippets, and utilities for Azure administration, operations, troubleshooting, and automation.

The repository contains tools developed by me from practical Azure engineering and operational tasks. The goal is to keep useful solutions in one place so they can be easily reused, adapted, and shared.

## What's Included

The toolkit may include:

- PowerShell scripts and functions
- Azure CLI commands and snippets
- Azure Resource Graph queries
- KQL queries
- Resource management utilities
- Networking and connectivity tools
- Identity and access management helpers
- Monitoring and diagnostics tools
- Troubleshooting utilities
- Automation examples
